# Sahaf - Kitap Satış Platformu

Modern ve kullanıcı dostu bir sahaf arayüzü. Bu proje, üniversite dersi kapsamında geliştirilmiş bir kitap satış platformu simülasyonudur.

## 🚀 Canlı Önizleme
Siteye buradan ulaşabilirsiniz: [https://umutefe.duckdns.org](https://umutefe.duckdns.org)

## ✨ Öne Çıkan Özellikler
- **Dinamik Kitap Listeleme:** Veritabanından çekilen güncel kitaplar.
- **LocalStorage Entegrasyonu:** Sepet ve Favoriler, kullanıcı giriş yapmasa bile tarayıcıda saklanır.
- **Backend Senkronizasyonu:** Giriş yapıldığında yerel veriler otomatik olarak hesapla eşzamanlanır.
- **Admin Paneli:** Kitap ekleme, silme ve sipariş yönetimi.
- **Favoriler Sistemi:** Kalp ikonu ile favoriye ekleme ve kolay erişim.

## 🛠️ Teknolojiler
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** PHP (MVC Yapısı)
- **Veritabanı:** MySQL
- **Sunucu:** Nginx / Linux
